# MailChannels Node.js Starter for Railway

A minimal Node.js starter template for sending transactional emails with MailChannels on Railway.

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/new/template/mailchannels)

## Prerequisites

- [Create a MailChannels account](https://www.mailchannels.com/pricing/#for_devs)
- [Create an API key](https://dash.mailchannels.com/account/api-keys)
